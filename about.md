Hi, I'm {{ site.author.name }}.

This is a small personal blog. It's built with [Jekyll][jekyll], stored as plain
Markdown in a git repository, and served for free by GitHub Pages. There is no
CMS, no analytics, and no JavaScript beyond what a page itself needs.

[jekyll]: https://jekyllrb.com/

## How it's put together

- Posts live in `_posts/` as `YYYY-MM-DD-title.md`.
- Images, PDFs, and any other binary attachment live in `assets/media/`.
- The theme is a handful of HTML layouts in `_layouts/` and one CSS file.
